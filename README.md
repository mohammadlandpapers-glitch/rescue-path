# rescue-path

An emergency portal and routing coordination application designed to streamline rescue paths and optimize response operations.

---

## 🚀 Features
* **Emergency Portal:** A centralized dashboard for tracking and managing real-time rescue requests.
* **Driver App Integration:** Dedicated interface/module for drivers to receive optimized navigation routes.
* **Robust Backend:** Secure server architecture handling request logs, routing data, and asset coordination.

## 📂 Project Structure
* `backend/` - Contains the server-side API, database logic, and routing scripts (e.g., `main.py`).
* `driver_app/` - Core files for the driver-facing application interface.
* `server.js` - Main Entry point for the Node.js/Express server environment.
* `index.html` - The primary landing portal interface.
